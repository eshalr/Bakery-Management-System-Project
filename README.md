# Bakery Management System

# Project Overview

A Java-based bakery management application developed as a group project. The system allows users to manage customer orders, customize bakery products, and calculate prices based on dessert selections and quantities.

The application uses object-oriented programming principles and Java Swing dialog boxes to provide an interactive ordering experience.

# Features

Order Management: Add, remove, search, and display customer orders.

Dessert Customization: Choose from cakes, cookies, and cupcakes with customizable flavors, toppings, fillings, and other options.

Customer Information: Record customer names, phone numbers, addresses, and payment methods.

Automatic Price Calculation: Calculate prices based on dessert type and quantity, including bulk-order discounts.

Input Validation: Check user inputs and display error messages for invalid entries.

Interactive Interface: Use Java Swing dialog boxes to navigate the system.

# How to Run

Download or clone this repository.

Open the project folder in Visual Studio Code with Java support installed.

Open BakeryImp.java.

Run the main() method.

Follow the on-screen prompts to manage bakery orders.

# Project Structure

BakeryImp.java – Main application and menu functionality.

BakeryShop.java – Connects orders, customer information, and desserts.

Dessert.java – Abstract superclass for bakery products.

Cake.java – Cake customization and pricing.

Cookie.java – Cookie customization and pricing.

Cupcake.java – Cupcake customization and pricing.

CustomerInfo.java – Customer details and payment information.

Order.java – Order identification and occasion details.

# Project Type

Collaborative Java programming project focused on applying object-oriented programming concepts to a bakery ordering system.
